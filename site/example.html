Example vault

A vault that teaches itself

The demo vault is a small research lab: five people, two companies, three projects, two papers and three topics. It uses every Typed Graph feature and includes a guide to typed graphs and a hands-on openCypher course. Every example in it runs live.

Download the vault (.zip) Browse on GitHub Try it in the browser

Open it in three steps

  1. Download and unzip typed-graph-demo-vault.zip. The plugin is already inside.
  2. In Obsidian, choose Open another vault → Open folder as vault and pick the unzipped folder.
  3. Turn on community plugins when Obsidian asks, then open Start Here.

If you work from a clone of the repository, npm install && npm run example:install builds the plugin straight into example/.

The Cypher manual

Each lesson is a few sentences and a live block you can edit. The result updates as you type.

  1. Nodes: MATCH, RETURN, labels and property maps
  2. Relationships: direction, type alternation, edge properties
  3. Filtering with WHERE: comparisons, IN, CONTAINS, IS NULL
  4. Signs and built-in properties: r.sign, r.id, n.stub, type(), labels()
  5. Several patterns at once, and longer chains
  6. OPTIONAL MATCH as a left join
  7. Aggregation: count, sum, avg, collect, DISTINCT
  8. Chaining with WITH, and filtering on an aggregate
  9. Variable-length paths and path variables
  10. Sorting and paging
  11. Stubs and schema checks written as queries
  12. Limits of the built-in engine, and when to use backend: ladybug
```graph-query
view: table

MATCH (p:Person)-[:contributes]->(proj:Project)
WITH p, count(proj) AS projects
WHERE projects > 1
RETURN p.title AS person, projects
```

What is in the data

The vault is small enough to read in ten minutes, and each feature appears somewhere in it:

  • Typed nodes in People/, Companies/, Projects/, Papers/ and Topics/, with frontmatter properties.
  • Multi-label nodes. Bob is [Person, Engineer] and Carol is [Engineer, Person], so the first label decides how each is drawn.
  • Typed edges with properties. Examples include contributes:: [[Ranking]] {hours: 200} and funds:: [[Search]] {amount: 250000, currency: EUR}.
  • Signed edges. Alice trusts Bob and distrusts Mallory, and Initech competes with Globex.
  • Pinned edge ids, used by the embeds in Alice's note.
  • Stubs. Eve, Globex and "Property Graphs 101" are linked but have no note yet.
  • Six schema notes in Types/, with required properties, allowed edges, colors, shapes, icons, a label property and templates.
  • Advisory schema warnings. Dave has no required role, and Mallory has an edge type her schema does not allow.

Tested like code

The vault is part of the test suite. Every query in it must parse and return rows, every embed must resolve, and the schema warnings and stubs must be exactly the deliberate ones. If the plugin changes in a way that breaks an example, the build fails before a release ships.
