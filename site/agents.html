Give your coding agent a memory it can query.

Stop re-explaining your architecture every session. TypeGraph gives Claude Code, Cursor and any MCP client a typed graph of your design docs and code, and a check that stops it from finishing with broken references.

See it work

Claude Code in one command

tg is a CLI your agent can call directly. tg init prints a diff of every file it would touch and writes only with --write.

npm install -g @typedgraph/cli
tg init --write      # CLAUDE.md block, hooks, .mcp.json, two skills
tg check             # does the documentation still match the code?

For Cursor use tg init --agent cursor; for a plain AGENTS.md use --agent agents.

What the agent gets

  1. Search first: a prompt hook reminds it to search, expands [[refs]] in your prompt and adds the top lexical hits. It needs no model, key or network.
  2. Query the graph: tg cypher over sections and code symbols, or the eight tools of tg mcp.
  3. Finish honestly: a stop hook blocks completion while tg check fails, or when several code lines changed with little change in the docs.

Memory engineering, not a pile of notes

Typed edges are memory an agent can traverse. Everything stays plain Markdown a human can review.

// @tg: implements:: [[auth#Token expiry]] {since: 2}
// @tg: -contradicts:: [[design#Stateless sessions]]
function legacyCheck() {}

$ tg cypher "MATCH (c:CodeSymbol)-[:implements]->(s:Section)
             RETURN s.title, count(c)"

Use an Obsidian vault as memory

Run the sidecar next to your vault to serve Cypher, vector search and cited GraphRAG over MCP.

claude mcp add typed-graph \
  -e OBSIGRAPH_VAULT=/path/to/vault \
  -e OBSIGRAPH_DATA=/path/to/data \
  -- node packages/sidecar/dist/server.mjs --stdio
