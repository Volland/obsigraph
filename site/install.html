Install Typed Graph.

One graph, four ways in. They all read the same Markdown, so use whichever fits where you work, and add the others later.

⚙

Claude Code and the CLI

Check, search, Cypher, agent setup and export. No Obsidian needed.

npm install -g @typedgraph/cli
tg init --write
tg mcp

Agents guide · CLI reference

◎

VS Code

Typed backlinks and the graph for Markdown and annotated code.

code --install-extension \
  pavlyshyn.typegraph-vscode

VS Code Marketplace

◎

Cursor, Windsurf, VSCodium, Gitpod

The same extension from Open VSX. Search TypeGraph in the Extensions view.

codium --install-extension \
  pavlyshyn.typegraph-vscode

Open VSX

◆

Obsidian

Settings → Community plugins → Browse → search Typed Graph → Install → Enable.

obsidian://show-plugin?id=typed-graph
