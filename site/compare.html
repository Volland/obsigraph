The honest version

vs lat.md

Typed Graph reads the same lat.md/ folders and agrees with lat check, so you can try it at no cost and use both. It adds typed edges from code, openCypher, a visual graph, no-setup search and an Obsidian plugin. lat.md is stronger on grammar-accurate symbol parsing, agent templates (Pi, OpenCode) and maturity. Read the full comparison.

vs plain Obsidian

Obsidian links say that two notes are related, not how. Typed Graph keeps your notes and your links and adds types, signs, properties, schemas, queries and a graph that follows the schema. Existing type:: [[Target]] lines keep working. Obsidian guide.

vs vector-only memory

Similarity finds text that looks like your question, but cannot say what implements what or what contradicts what. Typed Graph retrieves by relationship, can add vectors on top, and returns cited results. If you only need fuzzy recall over loose notes, a vector store alone is simpler. Vault as RAG storage.

Switching from lat.md

Your lat.md/ folder and @lat: comments stay as they are.

npm install -g @typedgraph/cli
tg check                       # should match lat check
tg init                        # dry run: see the diff
tg init --write --migrate      # swap the lat block, hooks and MCP entry
